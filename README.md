One warning label, at most 120 characters, for a time machine — built for [make.fun](https://make.fun)'s "Funniest Time Machine Warning Label" bounty ($2 in USDC).

The label: a straight-faced safety notice about butterflies, with the surprise saved for the last words — one already cost us the entire 21st century.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`.
